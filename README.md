# Spyro: Reignited Auto-Splitter

A cross-platform auto-splitter for Spyro: Reignited Trilogy.

> [!warning]
> 
> This is the legacy version of the auto-splitter I wrote when I was first learning how to program in Rust. As such, the code base is messy, and the auto-splitter itself isn't free from bugs. Please switch to the [default branch](https://github.com/KatieZeldaKat/spyro-rt-autosplitter) to see the current version.
